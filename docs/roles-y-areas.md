# Janery — roles, cargos y áreas

## 1. Cargos identificados

- Administración.
- Presidencia.
- Vicepresidencia.
- Secretaría.
- Tesorería.
- Caja chica.
- Comité de crédito.
- Asuntos sociales.

Cada cargo tendrá su área de trabajo. Las funciones específicas se definirán posteriormente; no inventarlas.

## 2. Separación conceptual

Distinguir:
- Usuario que inicia sesión.
- Persona registrada para operar.
- Condición de cliente.
- Condición de socio.
- Cargo organizativo.
- Permisos concretos.

Una persona puede ser cliente y socio simultáneamente y acceder a su panel personal y a las áreas que le correspondan.

## 3. Permisos

El sistema debe permitir permisos granulares como consultar, crear, revisar, aprobar, rechazar, registrar pagos, desembolsar, anular, administrar parámetros y consultar informes. Esta es una capacidad técnica, no una asignación aprobada a cada cargo.

## 4. Seguridad y evolución

Validar permisos en backend. Registrar asignación, cambio y revocación de cargos. Permitir múltiples cargos cuando las reglas lo autoricen. Definir posteriormente separación de funciones, suplencias, límites y aprobaciones.
